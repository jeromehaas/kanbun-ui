# [UI] Kanbun

![Vue](https://img.shields.io/badge/Vue-3.x-green)
![Vite](https://img.shields.io/badge/Vite-Build_Tool-purple)
![Tailwind CSS](https://img.shields.io/badge/Tailwind_CSS-4.x-blue)

Kanbun UI is the web-based interface for the Kanbun project, built with Vue 3 and Vite. It provides a visual kanban board experience with full support for managing boards, lanes, and tasks. The UI communicates with the Kanbun server to display and update project data in real time, and supports drag-and-drop task management across lanes.

## Requirements
- Node.js
- A reachable and configured kanbun-server

## Installation
Install dependencies:

```bash
npm install
```
